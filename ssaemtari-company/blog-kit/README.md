# 쌤태리 블로그 기획 키트

재개발 매물 네이버 블로그 원고를 쓰는 기준입니다. 2026년 10월 10일~24일 작업을 정리한 키트를 그대로 넣었고,
이 저장소에서 Claude에게 원고를 요청하면 이 기준(`.claude/skills/ssaemtari-blog/SKILL.md`)대로 씁니다.

## 원고 요청하는 법 (이 저장소에서)

파일을 따로 첨부할 필요가 없습니다.

1. `03_프롬프트/2_구역_요청_양식.txt`를 채워 붙여 넣고 "블로그 원고 써줘"라고 요청합니다.
2. 매물 분석표 · 네이버 매물 캡처 · 재개발 앱 화면을 함께 첨부합니다. 핵심 숫자는 글로도 적어 주세요.
3. 원고는 `04_완성원고/`에 Word 파일로 저장되고, 대화에도 파일로 보내 드립니다.
4. 유튜브용은 `03_프롬프트/3_유튜브_요청_프롬프트.txt`를 채워 요청합니다.

다른 Claude 대화(claude.ai)에서 쓸 때는 `00_먼저_읽어주세요.docx`의 방법대로 01 · 02 문서와 프롬프트를 첨부하면 됩니다.
