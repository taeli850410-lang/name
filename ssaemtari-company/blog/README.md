# 쌤태리 블로그 기획 키트

2026년 10월 10일~24일에 정한 재개발 매물 블로그 작성 기준입니다. 앞으로 블로그 원고는 이 기준, 특히 「02_작성기준_및_샘플」의 **13블록 형식**(썸네일 카드 · 가운데 인용구 · 인포그래픽 문구 · 상담 안내 카드)으로 만듭니다.

## Claude Code(이 저장소)에서 원고 받기

이 저장소에는 `.claude/skills/ssaemtari-blog` 스킬이 들어 있어서, 블로그 원고를 요청하면 Claude가 아래 기준 문서를 읽고 같은 순서로 작업합니다. 기준 문서나 프롬프트를 따로 첨부하지 않아도 됩니다.

1. [`03_프롬프트/2_구역_요청_양식.txt`](03_프롬프트/2_구역_요청_양식.txt)를 채워 붙이고, 매물 분석표 · 네이버 매물 · 재개발 앱 화면을 첨부합니다.
   예: "아래 양식으로 ○○구역 블로그 원고 써줘"
2. Claude가 커넥터로 실거래 약 10건 · 건축물대장 · 구역 고시 · 시장 지수를 조회하고, 판단을 바꿀 쟁점을 찾고, 계산합니다.
3. 원고는 Word 파일로 [`04_완성원고/`](04_완성원고/)에 저장되고, 만든 코드는 [`05_원고생성_코드/`](05_원고생성_코드/)에 남습니다. 게시 전 점검 스크립트(`../tools/check_blog_post.py`)를 통과한 뒤 커밋합니다.
4. 유튜브 제목 · 설명란은 "방금 원고로 유튜브 제목이랑 설명란 만들어줘"라고 요청하면 됩니다.

## claude.ai 새 대화에서 원고 받기

[`00_먼저_읽어주세요.docx`](00_먼저_읽어주세요.docx)의 방법 그대로입니다. `01_기획서.docx`와 `02_작성기준_및_샘플.docx`를 첨부하고 [`03_프롬프트/1_새대화_시작_프롬프트.txt`](03_프롬프트/1_새대화_시작_프롬프트.txt) 아래에 구역 요청 양식을 붙입니다. Word 모양까지 같게 받으려면 `05_원고생성_코드/blog_kit.js`와 `원고_템플릿.js`도 첨부합니다.
