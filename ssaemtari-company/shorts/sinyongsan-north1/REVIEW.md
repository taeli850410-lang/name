# REVIEW — 신용산역 북측1구역 근생 쇼츠

## 정한 것

- **세로 9:16** 을 골랐다. 쇼츠 요청이고, 화면 아래 1/3(1330 px 아래)은 플랫폼 UI 자리라 읽을 글자를 두지 않고 장면 번호만 크게 깔았다.
- **줄거리 하나로 바로 만들었다.** 요청이 "영상 생성 후 표시"라 HyperFrames 의 세 갈래 줄거리 제안 단계는 건너뛰었다.
  흐름은 블로그 순서를 따른다: 훅(19.5억 상가) → 질문 → 추산서 숫자 → 근생 아파트 조건 → 판정 → 115A 비용 → 신축 비교 → 입지 → 시점과 고지 → 상담.
- **하드컷 플래시**: 장면 사이 9번, 장면 안 샷 사이 7번. 흰색과 노란색을 번갈아 쓰고, 빨간 플래시는 쓰지 않았다(광과민).
- **숫자 카운트업은 오도미터**로 만들었다. 렌더러가 탐색할 때 콜백을 건너뛸 수 있어, 글자를 바꾸는 대신 0~9 띠를 굴린다.
- 블로그의 "용산에서 최고" 같은 단정 표현은 넣지 않았다.

## 2차 수정 — 본인 목소리, 60초에 맞춘 대본

- 의뢰인 요청: 첫 버전 목소리(Supertonic F4)가 기계 같다 → 본인 녹음을 참고한 목소리로, 전문가 톤, 60초.
- 녹음 5개는 다른 구역 설명이라 대본으로 쓰지 않고 10초만 참고 음성으로 썼다. 비교 샘플 12개 중 의뢰인이 11번(또렷한 아나운서)을 골랐다.
- 본인 말 속도로는 원래 대본이 약 94초라, 숫자 화면은 그대로 두고 말을 약 300음절로 줄였다.
- 첫 버전이 기계 같았던 원인 추정: 쉼표마다 끊어 합성 + 1.13배속. 이번엔 줄마다 통째로 합성한다.
- 시각을 손으로 넣지 않는다. 완성된 음성의 단어별 시각으로 장면·자막·효과음을 계산하도록 빌드를 바꿨다.

- 결과: 말소리 56.5초 + 끝 화면, 60.0초. 12줄 모두 Whisper 로 숫자 확인 통과. "평형"은 [평영](ㅎ 약화)으로 들려
  자연스러운 발음으로 보고 그대로 두었고, "지위"는 같은 소리 "지휘"로 인식돼 정확.
- 음량: 렌더 원본이 -12.4 LUFS 라 전체 믹스를 ×0.74(-2.6 dB) → -15.1 LUFS, 최대 -3.6 dBFS. build.py 의 MIX 에도 넣었다.

## 3차 수정 — 마지막 멘트, 토끼 아나운서

- 마지막 줄을 "자세한 정보를 알고 싶으시면 연락주세요."로 바꿨다. 화면도 "연락주세요"를 크게, 상호는 그 아래.
- 의뢰인이 준 토끼 캐릭터(파란 재킷·라펠 마이크)를 처음엔 왼쪽 아래 240px 원에 넣었다가, 요청대로 오른쪽 맨 위 200px 원으로 옮겼다.
  위 168px 은 앱 상단 UI 자리라 그 바로 아래. 겹치던 장면(3·4·5·7·8)은 글자 크기·위치를 조정했다.
  입은 내레이션 RMS(30fps, -42~-18 dB → 0~1, 4단계)로, 고개는 느린 사인 흔들림 × 말소리 에너지 + 효과음 순간의 끄덕임,
  눈은 2.6~4.6초 간격 깜빡임. 끝 화면 직전에 원이 빠진다.
- 한계: 입 모양(ㅏ·ㅗ 등)을 맞추는 모델이 아니라 소리 크기에 따라 벌어지는 2D 입이다. 진짜 립싱크는 HeyGen 말하는 사진 등이 필요하다.

## 4차 수정 — 토끼 빼기, 배경음악, 중개사무소 표시

- 토끼 아나운서를 뺐다(코드·이미지 삭제). 토끼 자리를 피하려고 줄이고 옮겼던 장면 3·4·5·7·8은 토끼 넣기 전 배치로 되돌렸고,
  "AI 음성" 꼬리표도 오른쪽 위 원래 자리로.
- 배경음악: `tools/bgm.py` 가 코드로 작곡·합성한다(외부 음원·생성 모델 없음 → 저작권 문제 없음, 매번 같은 소리).
  약 115.6 BPM, Am–F–C–G, 끝은 C(add9). 마디 경계를 두 순간에 맞췄다 — 12마디 = 장면 5 도장(24.75 s, 직전 한 마디는 킥·베이스를 빼고 라이저),
  27마디 = 끝 화면 컷(55.89 s, 한 방). 내레이션 동안 -9 dB 덕킹, 2.5 kHz 를 -4 dB 비워 말소리 자리를 둔다.
- 끝 화면: 의뢰인 명함 그대로 — (주)센츄리21부동산중개법인 / 이태리 공인중개사 / Mobile·Direct·E-mail / 주소 / 프랜차이즈 문구.
  그 아래 매물 표시 사항과 추산서 고지. 작은 글씨를 모두 28px 이상으로(폰에서 읽히는 하한). 아래 오른쪽은 앱 버튼 자리라 오른쪽 여백 130px.
  "연락주세요" 화면에는 휴대폰 번호를 크게, 사무소·이름을 그 아래 넣었다.
- 표시 사항은 `office.json` 에서 읽는다. 등록번호·대표자 성명이 비어 있으면 build.py 가 경고한다(6차에서 채움).
- 믹스(렌더러와 같은 단순 합으로 미리 계산): 내레이션 -15.7 LUFS, 말하는 동안 음악은 약 13 dB 아래, 끝 화면에서 음악이 -20 LUFS 로 올라온다.
  렌더러가 모노 내레이션을 +3 dB 로 섞는 것을 지난 렌더와 비교해 확인하고 반영했다.

## 5차 수정 — 마지막 "연락주세요" 한 번만

- 마지막 줄(l12)은 화면의 큰 글자가 내레이션과 똑같아 자막을 달지 않는다(build.py `NO_CAPTION`). 자막 29개 → 27개.

## 6차 수정 — 등록번호·대표 공인중개사, 끝 화면 8초

- 의뢰인이 준 표시 사항을 `office.json` 에 채웠다: 등록번호 11680-2017-00222, 대표 공인중개사 김동현,
  연락처는 준 형식대로 하이픈(010-4286-0252 / 02-2027-7073). 주소 아래 한 줄로 들어가고 매물 정보 블록을 46px 내렸다.
- "검은 화면을 더 오래": 내레이션은 그대로 두고 영상 끝을 60 → 64초로 늘려 끝 화면이 약 4.1초 → 8.1초 선다.
  배경음악은 끝 화면 동안 C–F–G 세 마디를 더 가다가 62.1초에 C(add9)로 닫는다(`bgm.py` 가 길이에서 마디 수를 계산).

## 잰 것과 보기만 한 것

- `hyperframes check`: lint · runtime · layout · audio · contrast · motion 오류 0.
- 내레이션: 27개 절을 Whisper(medium)로 되읽어 숫자가 자막과 같은 TTS 시드를 골랐다. 전체 트랙도 줄마다 다시 확인했다.
  "업무"는 표준 발음 [엄무]라 인식기가 "연무"로 적지만 숫자는 모두 일치.
- 소리는 **측정만 했고 듣지 않았다**. 효과음은 파일마다 정점 시각을 재서 그림보다 한 프레임 뒤에 맞췄다. 배경음악도 음량·스펙트럼·박자 위치만 쟀다.
- 장면별 스냅샷(시작·중간, 컷 전후)을 눈으로 확인했다.
