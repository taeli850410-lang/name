# 쌤태리 재개발 매물 블로그 원고

대표님이 2026년 10월에 정한 블로그 작성 방식이다. 원본 기준은 `ssaemtari-company/blog-kit/` 에 있다.
이 파일은 그 기준을 작업 순서대로 줄인 것이고, 애매하면 원본을 따른다.

## 독자와 최종 기준

- 독자는 재개발 매물을 검토하는 일반 투자자다. 속으로 묻는 세 질문, **"이 값을 줘도 되나", "새집을 정말 받을 수 있나", "잘못 계약할 위험은 없나"** 에 답하는 순서로 쓴다.
- 목표는 조회수보다 신뢰와 상담 전환이다. 광고가 아니라 "내 상황을 정확히 이해해 주는 전문가"로 읽혀야 한다.
- 검수 점수: 정확성 30 + 고객가치 25 + 신뢰 20 + 이해도 15 + 차별성 10. 90점 미만이면 한 번 더 고친다.

## 1. 자료 받기

대표님이 「2_구역_요청_양식」을 채워 보내고 매물 분석표 · 네이버 매물 · 재개발 앱 이미지를 첨부한다.
양식 없이 요청이 오면 `03_프롬프트/2_구역_요청_양식.txt` 를 보여 주고 빈칸을 물어본다.

- 뽑을 숫자: 매매가, 대지(지분) ㎡ · 평, 건물 면적, 사용승인일, 감정평가액(통지 / 추정 구분), 조합원 분양가와 평형, 비례율, 사업 단계, 임대 조건, 매물 출처, 비교할 옆 신축, 이 구역 이전 글 제목.
- 이미지가 흐려 안 읽히는 숫자는 지어내지 않는다. 빈칸으로 두고 물어본다.
- 매물 출처가 다른 사무소면 광고 가능 여부(의뢰 · 공동중개 관계)를 먼저 확인하라고 알린다.

## 2. 커넥터 조회 (실거래 약 10건)

| 커넥터 | 쓰는 도구 | 얻는 것 | 주의 |
| --- | --- | --- | --- |
| 국토부 실거래 | `mcp__real-estate__get_region_code` → `get_single_house_trades` · `get_villa_trades` · `get_apartment_trades` · `get_commercial_trade` (전월세는 `*_rent`), 흐름은 `summarize_market` | 실거래 10건 표, 옆 신축 시세, 월세 시세 | 최근 1~2달은 신고가 덜 잡힌다. 단독은 지번이 가려진다. 직거래 · 해제 거래는 뺀다 |
| hofinder | `mcp__hofinder__get_recent_deals` · `analyze_building` · `verify_listing` | 거래마다 대지 면적 · 지분, 지번 앞자리 → 대지 평당가, 구역 번지대 거래 골라내기 | 코드 조회의 번지 필터는 0건이 나와서 지역 조회 후 직접 거른다 |

| VWorld | `mcp__vworld__geocode_address` · `get_land_parcel` | 좌표 · 필지 · 용도지역 | 일부 지번은 조회되지 않는다 |

| 웹 검색 | `WebSearch` | 사업 단계, 시공사, 세대수, 최근 발표, 고시 · 법령 | 기사 날짜를 꼭 확인. 자료마다 숫자가 다르면 둘 다 적는다 |

도구가 연결돼 있지 않거나 조회가 안 되면 숫자를 지어내지 말고, 무엇이 안 됐는지 말하고 대표님께 붙여 넣어 달라고 한다.
지번이 가려진 거래는 "구역 안인지 확인하지 못했습니다" 각주를 단다.

## 3. 쟁점 찾기 — 가장 중요한 단계

이 매물의 판단을 뒤집을 사실 1~2개를 찾아 **글의 중심축**으로 놓는다. 숨기지 않는다.
예: 후보지 발표에서 빠짐((가)논현1동), 근생의 아파트 분양자격 조례(신용산역 북측1구역), 다른 사무소 매물이라 광고 가능 여부(동후암1구역), 프리미엄이 한계선을 넘음, 토지거래허가로 임대 구조가 막힘.

매물 유형별로 먼저 볼 것 (01_기획서 5번):

- **무허가주택:** 분양자격 서류, 무허가건축물관리대장 명의 변경 특약, 국공유지 점유 사용료. 권리가액이 낮으면 선택 분양 경쟁에서 불리할 수 있음
- **빌라 · 다세대:** 분양신청 여부와 평형(안 하면 현금청산), 감정평가 통지액, 토지거래허가, 투기과열지구 조합원 지위
- **신축 다세대 · 도심복합:** 후보지 선정 여부(2025년 8월 개정으로 새 후보지는 선정일이 우선공급 기준일), 개발이 늦어져도 버틸 가격인지(월세 · 옆 건물 실거래), 토지거래허가와 임차인 승계 충돌
- **단독 · 초기 단계:** 사용승인일 vs 권리산정기준일, 추진위 단계의 긴 시간 비용, 월세 수익률, 다른 사무소 매물이면 광고 가능 여부부터
- **근생 · 상가:** 서울시 조례상 종전 토지 90㎡ 이상 또는 권리가액 ≥ 분양용 최소규모 공동주택 1가구 추산액이어야 아파트 분양. 아니면 상가 분양 또는 현금청산. 대출 · 취득세 기준도 다름

공통 규정은 일반 원칙으로만 쓰고 "개별 매물은 구청 · 전문가 확인"을 붙인다: 토지거래허가(서울시 기준면적 주거 6㎡ · 상업 15㎡ 초과), 투기과열지구(관리처분인가 후 매수자는 원칙적으로 조합원 불가, 5년 재당첨 제한), 분양신청 기간 놓치면 현금청산, '관리처분 예정'이 신청인지 인가인지 구분.

## 4. 계산

| 계산 | 공식 |
| --- | --- |
| 대지 평당가 | 매매가 ÷ 대지(평) |
| 프리미엄 | 매매가 − 감정평가액 |
| 권리가액 | 감정평가액 × 비례율 (모르면 90 · 100 · 110% 시나리오) |
| 총투자금 | 매매가 + 분담금 (= 프리미엄 + 조합원 분양가) |
| 프리미엄 한계선 | 옆 신축 같은 평형 실거래 − 조합원 분양가 |
| 분담금 한계선 (초기 단계) | 옆 신축 실거래 − 매매가 |
| 월세 수익률 | 연 월세 ÷ (매매가 − 보증금) |

한계선은 상한선이지 목표가 아니다. 기다리는 기간의 이자 · 이주비 · 추가 분담금이 빠져 있다는 문장을 계산 옆에 항상 쓴다. 추정치는 '추정', 가정은 '가정'이라고 적는다.

## 5. 구성 — 쌤태리 13블록

| 순서 | 블록 | 넣을 것 |
| --- | --- | --- |
| 1 | 썸네일 카드 | 지역 · 유형 · 매매가 · 왕관 줄 · 하단 태그 2개 · 카드 색 (구역별 색 통일: 용산 빨강, 마천 연두) |
| 2 | 제목 | 아래 제목 공식 |
| 3 | 날짜 줄 · 도입 | 작은 회색 "N부동산 매물현황 YYYY.MM.DD  매물은 실시간 확인이 필요하므로 반드시 전문가와 상담하세요." (오늘 날짜) → 감성 도입 3~4줄 → 노란 형광 결론 1줄 |
| 4 | 가운데 인용구 | 설렘과 불안 두 줄 (따옴표형, 가운데) |
| 5 | 매물 표 | 마지막 행 매매가 노란색 + 중개사 한 줄 |
| 6 | 현장 사진 · 이전 글 | [사진] 현장 · 거리, [이전 글 링크 카드] |
| 7 | 실거래 | 실거래 표 약 10건 + [인포그래픽] 실거래 분석 (그래프 + 비교표 + 하단 배너) |
| 8 | 핵심 계산 | 권리가액 · 비례율 또는 프리미엄 한계선 표 + [인포그래픽] 계산 카드 |
| 9 | 위치 · 주변 개발 | [인포그래픽] 지도 (구역 빨강, 비교 단지 파랑, 하단 배너) |
| 10 | 사업 일정 | 일정 표 (현재 단계 강조) + [영상] 조감 · 드론 |
| 11 | 체크리스트 | 번호 목록 5개 + [인포그래픽] 체크리스트 카드 (아이콘 5개 + 하단 배너) |
| 12 | 마치며 | 감성 마무리 3~4줄 + 노란 형광 결론 |
| 13 | 상담 안내 | [상담 안내 카드 문구] (필수 표기 포함) + 조감도 + 해시태그 10개 안팎 |

- 바뀌지 않는 세 가지: **매물이 먼저, 실거래 약 10건, 사실 → 의미 → 판단.** 실거래와 계산 중 그 구역에서 더 강한 쪽을 앞에 둬도 된다.
- [인포그래픽 n] 자리에는 제목 · 들어갈 내용 · 하단 배너 결론 한 줄 · 캡션을 적는다. 배너 예: "시장 가격의 대부분은 '상가'보다 '아파트 자격'에 붙은 값".
- 서식 수량: 초록 '중개사 한 줄' 4~5개, 노란 형광 5~6곳, 핵심 키워드는 파란 굵은 글씨(키워드마다 1~2번, 억지 반복 금지). 소제목은 SEO 문구 말고 사람이 궁금해할 말로, 핵심 키워드를 자연스럽게 넣는다.
- 경험이 들어갈 자리는 [직접 경험] 박스로 비워 둔다. 대표님이 채우거나 지운다.
- 마지막 페이지는 작성자 참고용: 제목 후보 10개(★ 추천), 가장 먼저 확인할 것, 게시 전 확인할 것(가정 · 추정 숫자와 근거), 출처 링크.

### 감성 30%

1. 독자의 속마음을 따옴표로 꺼낸다 ('아직 늦지 않았나', '상가로도 아파트가 나오나') — 제목 · 인용구 · 소제목에.
2. **숫자 → 그 숫자 앞에서 드는 마음 → 계산** 순서로 쓴다.
3. 설렘과 불안을 한 문단에 짝으로 넣는다. 기대만 쓰면 광고, 걱정만 쓰면 겁주기로 읽힌다.
4. '솔직히 말씀드리면', '저라면'은 대표님의 실제 판단 기준일 때만 쓰고, 작성자 참고용에 "실제 기준과 다르면 고쳐 주세요"라고 남긴다.
5. 긴 설명 두 문장 뒤에 짧은 판단 한 문장을 둔다.
6. 도입 · 마치며는 감성 절반, 본문 섹션은 한두 줄(약 20%). 전체로 약 30%.

예) 사실만: "프리미엄은 4억4,300만 원입니다." → 감성 30%: "프리미엄 4억4,300만 원. '아직 늦지 않았나' 싶은 숫자입니다. 그래서 기준을 바꿔 계산해 봤습니다. 지금 시세가 아니라 **입주할 때 옆 신축 시세**로요."

### 제목 공식

- **A. 확인형:** [구역명] + 단계 · 브랜드 + 매물 + '살 때 꼭 확인할 N가지'
- **B. 속마음형:** 구역명 + 가격대 매물 + '속마음' + 팩트 체크
- **C. 질문 · 숫자형:** 구역명 + 매물 가격 + 독자의 질문 + '숫자로 답합니다'
- 구역명 맨 앞, 앞 25자 안에 매물 유형과 가격, 전체 30~40자. 이번에 새로 찾은 가장 강한 데이터를 꺼낸다.
- 이전 글 제목과 첫 단어 · 문장 구조 · 중심 소재가 겹치지 않게, 직전 글과 같은 공식을 연달아 쓰지 않는다.
- 가정으로만 나오는 숫자(분양가 가정 총투자금 등)와 '최저'처럼 사실과 다를 수 있는 말은 제목에 넣지 않는다.
- 10개를 만들고 1개를 추천한다.

## 지키는 원칙

- **숫자를 만들지 않는다.** 제공되거나 조회된 숫자만 쓰고, 추정치는 '추정'으로, 출처를 남긴다.
- **경험을 지어내지 않는다.** 남의 임장 후기는 "방문기들을 보면", 상담 질문은 "이 매물 앞에서 던져야 할 질문"으로 쓴다.
- **표시 · 광고 규정:** 다른 사무소 매물은 관계 확인 후. 상담 카드에 중개사무소 명칭 · 소재지 · 연락처 · 등록번호 · 대표 공인중개사 성명.
- **쓰지 않는 말:** "무조건 오른다", "지금 안 사면 후회", "마지막 기회", "확정 수익", "안녕하세요, 오늘은 알아보겠습니다", "많은 분들이 궁금해하시는데요", "끝까지 읽어주세요".

## 6. Word 원고 만들기

`ssaemtari-company/blog-kit/05_원고생성_코드` 에서:

```bash
npm install                                   # 처음 한 번 (docx 9.5.1)
cp 원고별/_템플릿.js 원고별/<구역>_<YYYYMMDD>.js  # {{ }} 자리를 모두 채운다
grep -n "{{" 원고별/<구역>_<YYYYMMDD>.js       # 비어 있어야 한다
node 원고별/<구역>_<YYYYMMDD>.js ../04_완성원고/<구역>_<유형>매물_블로그원고.docx
```

- 블록 함수와 마크업(`**굵게**`, `==형광==`, `^^파란 키워드^^`)은 `05_원고생성_코드/README_코드.txt` 참고. 표 열 너비 합계는 9638.
- 같은 매물을 고치면 파일 이름에 `_v2`, `_v3` 를 붙이고 이전 판은 `04_완성원고/이전버전/` 으로 옮긴다.
- 렌더링 확인: `soffice --headless --convert-to pdf` → `pdftoppm -png -r 50` → 페이지 이미지를 직접 보고 표 · 박스가 페이지 사이에서 깨지지 않는지 본다. 결과물은 스크래치패드에 만든다.

## 7. 검수 · 전달

게시 전 체크리스트 (01_기획서 12번)를 하나씩 확인한다:

1. 날짜 줄이 게시하는 날이다
2. 매물 숫자(매매가 · 대지 · 감정가 · 분양가와 평형)를 원자료와 다시 맞췄다
3. 지번이 가려진 실거래에 각주가 있다
4. 사업 단계 표현(신청 / 인가)이 정확하다
5. 광고할 수 있는 매물이고 필수 표기가 들어갔다
6. [직접 경험] 박스가 있으면 작성자 참고용에 "채우거나 지우기"를 남겼다
7. 형광펜 5~6곳, 키워드 억지 반복 없음
8. 조감도 · 지도 등 이미지 출처 표기 자리가 있다
9. 해시태그 10개 안팎

그다음 QS 점수(정확성 30 · 고객가치 25 · 신뢰 20 · 이해도 15 · 차별성 10)를 매겨 90점 미만이면 고친다.

전달: docx 를 `SendUserFile` 로 보내고, 답장에는 추천 제목 + 후보 몇 개, 글의 중심축(쟁점) 한 줄, 대표님이 게시 전에 확인할 것만 짧게 쓴다. 원고 스크립트와 docx 는 커밋해 둔다.

## 유튜브 제목 · 설명란

원고가 나온 뒤 요청하면 `03_프롬프트/3_유튜브_요청_프롬프트.txt` 와 01_기획서 9번대로 만든다.

- 제목: 후킹 제목 8개 + 추천 2개. 숫자 충격 + 궁금증("땅 2.42평에 5억? 성북2구역 매물, 평당 2억의 정체"), 기대 → 반전("5억인 줄 알았는데… 계산기 끝까지 두드려 봤습니다"). 가정으로만 나오는 숫자는 넣지 않는다. 쇼츠는 40자 안팎.
- 썸네일과 한 세트: 썸네일이 질문을 던지면 제목은 반전을 흘린다. 썸네일에 없는 숫자를 하나 더 넣는다.
- 설명란 순서: 첫 2~3줄 가장 강한 문장('더보기' 위) → ✔ 핵심 숫자 5~6줄 → 판단 한 줄 → ※ 추정치 고지 → ▶ 목차(첫 줄은 반드시 00:00) → ▶ 매물 정보(사무소 명칭 · 소재지 · 연락처 · 등록번호 · 대표 성명, 매물 소재지 · 종류 · 거래형태 · 가격 · 면적) → 해시태그(앞 3개가 제목 위에 표시, 쇼츠는 #shorts).
