# 성북2구역 지역 소개 · 상담 유도 영상 v4 (9:16, 60초)

가격·면적·분담금 등 매물 정보는 공개하지 않고, **입지와 사업 전망**으로 관심을 끈 뒤
"얼마가 필요할까? → 1:1 상담 시 공개" → 연락처로 이어지게 만든 지역 소개 영상입니다.

- 특정 매물 광고가 아닌 **지역·사업 소개** 형식 — 인터넷 중개대상물 광고는 소재지·면적·가격 등을 밝혀야 해서(공인중개사법 제18조의2) 매물 자체는 다루지 않음
- 단정적 수익 표현("무조건 오른다" 등) 없음
- "새 아파트" 대신 **"새 주거단지"** — 최고 4층 계획이라 법상 아파트(5층 이상)가 아님

| 파일 | 내용 |
|---|---|
| `seongbuk2_v4_lead.mp4` / `.srt` | 완성 영상 (1080×1920, 30fps, 60.0초, -16 LUFS) / 자막 |
| `render2.py` | 렌더러 — 이번 장면은 파일 끝의 `n1`~`n8`, 지도는 `GEO`·`map_panel` |
| `gen_native.py`, `style_mix.json` | 한국어 원어민 음성(Supertonic-3, 여성 프리셋 혼합)으로 내레이션 생성 + Whisper 받아쓰기 검증 |
| `endcard.py` | 마지막 중개사 정보 화면(명함 스타일, 매물 정보·안내 문구 없음) |

사진·영상 자료는 `../seongbuk2-rabbit/assets`를 사용합니다.

## 만들기

```bash
python3 gen_native.py                 # 내레이션 (받아쓰기 검증 포함)
python3 render2.py mix out && python3 render2.py render out
```
전체 60초에 맞추려면 `END_CARD`(정보 화면 길이)를 60 − (내레이션 장면 길이 합)으로 둡니다.
